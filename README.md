# 💰 TGF Contábil - Gestão Financeira Inteligente

O **TGF Contábil** é uma aplicação web focada em simplificar o controle financeiro pessoal ou empresarial. Através de uma interface limpa e funcional, o usuário pode monitorar seu fluxo de caixa, categorizar gastos e visualizar o desempenho financeiro através de gráficos dinâmicos.

---

## ✨ Funcionalidades

* **📈 Dashboard de Saldo:** Visualização instantânea de Entradas, Saídas e Total acumulado.
* **💸 Gestão de Transações (CRUD):** Adicione, edite e exclua registros de forma intuitiva.
* **📊 Análise por Categoria:** Gráfico de rosca dinâmico para identificar onde você está gastando mais.
* **📅 Filtros Inteligentes:** Visualize dados por períodos específicos (7 dias, 30 dias ou datas personalizadas).
* **💱 Suporte Multimoeda:** Alterne a visualização entre Real (BRL), Dólar (USD), Euro (EUR) e Libra (GBP).
* **📄 Exportação em PDF:** Gere relatórios profissionais detalhados dos seus lançamentos.
* **💾 Persistência Local:** Seus dados ficam salvos no `localStorage` do navegador, sem necessidade de banco de dados externo.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando tecnologias fundamentais da web para garantir performance e leveza:

* **HTML5 & CSS3:** Estrutura semântica e estilização moderna com foco em responsividade (Mobile First).
* **JavaScript (ES6+):** Lógica de manipulação de dados, cálculos financeiros e controle do DOM.
* **[Chart.js](https://www.chartjs.org/):** Renderização de gráficos interativos.
* **[jsPDF](https://parall.ax/products/jspdf):** Biblioteca para geração dos relatórios em PDF.
* **[Phosphor Icons](https://phosphoricons.com/):** Biblioteca de ícones versáteis utilizados na interface.
